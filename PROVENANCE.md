# Source provenance

This candidate derives from the existing BNIK Software Factory project. It
preserves the service implementations, tests, and locked dependency references,
with generic examples and revised development documentation. It starts a new
Git history; its root commit is an assembly record, not a claim of sole authorship.
The maintainer retains the original contributor records and a per-file source map.

No first-party copyright or license notices were removed from the selected source.
No third-party implementation, installed dependency tree, vendor binary, or image
is vendored in this source tree. Package lockfiles retain dependency identities,
integrities, and license metadata. See [THIRD_PARTY.md](THIRD_PARTY.md).

Apache-2.0 has been selected for project-owned source; see [LICENSE](LICENSE).
The exact rights-holder notice and public maintainer attribution are being finalized
before distribution. Dependencies keep their own terms. Required notices must
accompany any later distributed source, binary or container artifact.
